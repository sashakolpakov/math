# Source and contribution credits

Discussions and model prompting were carried out by **Alexander Kolpakov
(UATX)** and **Nikolay Bogachev (University of Toronto)**.

The manuscript and this Lean project were imported from
[`sashakolpakov/arithmetic-trace-rigidity`](https://github.com/sashakolpakov/arithmetic-trace-rigidity)
at commit `2dc96272295b99c4932e8f71c9973deeef26581f`
(9 October 2026). The source working directory was clean when imported.

The contribution adds the discussion and prompting credits to the TeX
source and Lean comments, rebuilds the PDF, and adapts the documentation
and verification script paths to this repository. The Lean theorem
statements, hypotheses, and proof bodies are preserved. The original Lean
4.32.2 toolchain and exact Lake dependency revisions are retained in this
standalone package.

The focused manuscript is a model-assisted working paper; the credits above
describe the humans' discussion and prompting roles. The original project's
[provenance and influence ledger](https://github.com/sashakolpakov/arithmetic-trace-rigidity/blob/2dc96272295b99c4932e8f71c9973deeef26581f/PROVENANCE_INFLUENCE_LEDGER.md)
distinguishes Bogachev's initial manuscript, subsequent development, and
external mathematical inputs.

The source project's historical release manifest describes the original
PDF, before the added credit footnote. The contributed manuscript has a
`SHA256SUMS` file for the revised source and PDF artifacts.

The formalization checks selected identities and deductions from explicit
analytic, geometric, and arithmetic hypotheses. It does not formalize the
entire geometric arithmeticity theorem.
See [the manuscript map](MANUSCRIPT_MAP.md) for the declaration-level scope.
